## 1. Typing Philosophy: Precision vs. Speed Mode

Lekhani provides a seamless dual-layer typing experience:

```
  ┌─────────────────────────────────────────────────────────────────────────┐
  │                           HOW LEKHANI WORKS                             │
  └────────────────────────────────────┬────────────────────────────────────┘
                                       │
                        ┌──────────────┴──────────────┐
                        ▼                             ▼
             [ Candidate Slot 0 ]            [ Candidate Slots 1.. ]
         Pure Avro Transliteration          Ergonomic Standard Suggestions
         (100% Keystroke Faithful)          (Bangla Academy Standard)
```

1. **Precision Mode (Slot 0)**:
   - Always guarantees **100% exact Avro phonetic transliteration**.
   - If you know exact Avro keys (e.g. `krriShNo` for `কৃষ্ণ`, `ut```shob` for `উৎসব`), pressing `Space` commits it instantly with zero surprises.
2. **Speed & Ergonomic Mode (Slots 1..)**:
   - If you type casually or phonetically (e.g. `bortoman`, `orthonoitik`, `muktijuddher`, `durniti`, `biddut`), Lekhani's fuzzy and dictionary engine automatically suggests the correct Bangla Academy standard spelling (`বর্তমান`, `অর্থনৈতিক`, `মুক্তিযুদ্ধের`, `দুর্নীতি`, `বিদ্যুৎ`) in the candidate list.
   - Press the corresponding number (`1`, `2`, ...) or `Tab`/`Down Arrow` + `Space` to pick.

## 2. Vowels & Kars (স্বরবর্ণ ও কারচিহ্ন)

In Bengali, vowels appear either as **independent letters** (at the start of a word or syllable) or as **vowel marks (কার)** attached to consonants.

| Bengali | Independent Key | Kar Example | Kar Keystroke | Description / Notes |
| :--- | :--- | :--- | :--- | :--- |
| **অ** | `o` / `a` | ক | `k` / `ko` | Inherent vowel |
| **আ / া** | `a` / `aa` / `A` | কা | `ka` / `kaa` / `kA` | Aa-kar |
| **ই / ি** | `i` | কি | `ki` | Hroshwo-I kar |
| **ঈ / ী** | `I` / `ee` | কী | `kI` / `kee` | Dirgho-I kar |
| **উ / ু** | `u` | কু | `ku` | Hroshwo-U kar |
| **ঊ / ূ** | `U` / `oo` | কূ | `kU` / `koo` | Dirgho-U kar |
| **ঋ / ৃ** | `rri` / `rre` | কৃ | `krri` / `krre` | Ri-kar |
| **এ / ে** | `e` | কে | `ke` | E-kar |
| **ঐ / ৈ** | `OI` / `oi` | কৈ | `kOI` / `koi` | Oi-kar (Diphthong) |
| **ও / ো** | `O` / `o` | কো | `kO` / `ko` | O-kar |
| **ঔ / ৌ** | `OU` / `ou` | কৌ | `kOU` / `kou` | Ou-kar (Diphthong) |

> [!TIP]
> **Coordinating Conjunction "ও"**: Typing a single letter `o` by itself automatically outputs **"ও"**.
> **Vowel Forming**: Typing `o` followed by `a` automatically merges into **"আ"** (`অ` + `া` ➔ `আ`).

### Verb Inflections (-ছেন, -ছিলেন, -চ্ছি) & Suffixes (-টা, -গুলো)

Lekhani's morphological engine automatically detects verb inflections and noun suffixes:

- **Polite / Present Continuous Verbs**:
  - `korchhen` ➔ suggests **করছেন**
  - `bolchhen` ➔ suggests **বলছেন**
  - `dekhchhen` ➔ suggests **দেখছেন**
  - `jacchi` / `jacchen` ➔ suggests **যাচ্ছি** / **যাচ্ছেন**
- **Noun Suffixes (`-টা`, `-টি`, `-গুলো`, `-দের`, `-কে`, `-তে`)**:
  - `boita` ➔ **বইটা**
  - `kajta` ➔ **কাজটা**
  - `manushgulo` ➔ **মানুষগুলো**
  - `shodoshyoder` ➔ **সদস্যদের**

## 5. Candidate Bar Controls & Keyboard Shortcuts

| Key / Action | Function |
| :--- | :--- |
| <kbd>Space</kbd> | Commits Candidate 0 (or currently highlighted item). |
| <kbd>Enter</kbd> | Commits pre-edit buffer directly. |
| <kbd>1</kbd> - <kbd>9</kbd> | Directly commits candidate at index 1 to 9. |
| <kbd>↓</kbd> / <kbd>Tab</kbd> | Highlights the next candidate in the dropdown. |
| <kbd>↑</kbd> / <kbd>Shift+Tab</kbd> | Highlights the previous candidate. |
| <kbd>Backspace</kbd> | Deletes the last typed letter from pre-edit buffer. |
| <kbd>F12</kbd> | Global hotkey to toggle between Bengali and English input mode. |

## 6. Built-in Productivity Power Tools

### Inline Math Calculator
Type any math formula ending with `=` or prefixed with `=`, and Lekhani calculates the result in Bengali numerals instantly:

```
=125*8     ➔  ১,০০০
500+250=   ➔  ৭৫০
```

### Live Currency Converter
Quickly convert global currencies to Bangladeshi Taka (৳):

```
#usd50     ➔  ৳৬,১০০
#eur100    ➔  ৳১৩,২০০
#gbp20     ➔  ৳৩,১০০
```

### Dynamic Macros & Date/Time
Generate dynamic dates and cultural greetings with dynamic shortcuts:

```
#tarikh        ➔  ১১ সেপ্টেম্বর ২০২৬
#shomoy        ➔  ০৫:০৫ অপরাহ্ন
!shubhechha    ➔  আপনাকে আন্তরিক শুভেচ্ছা ও অভিনন্দন।
```

### Semantic Emoji & Bengali Symbol Shortcuts
Type shortcodes flanked by `:` or `*`:

| Shortcut | Expanded Output |
| :--- | :---: |
| `:bhalobasha:` | ❤️ |
| `:cha:` | ☕ |
| `:daktar:` | 🩺 |
| `:pani:` | 💧 |
| `:shurjo:` | ☀️ |
| `*taka*` | ৳ |
| `*dari*` | । |

### Bijoy (ANSI) ⇄ Unicode Converter
Convert legacy documents between SutonnyMJ/Bijoy and standard Unicode with 1-click inside `lekhani-gui` or via CLI (`lekhani convert`).
